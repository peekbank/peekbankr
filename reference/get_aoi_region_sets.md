# Get AOI region sets

**\[superseded\]**

Use `pb$aoi_region_sets` on a
[`peekbank()`](https://peekbank.github.io/peekbankr/reference/peekbank.md)
client.

## Usage

``` r
get_aoi_region_sets(connection = NULL)
```

## Arguments

- connection:

  A connection to the peekbank database

## Value

A tibble of AOI Region Sets data, filtered down by supplied arguments.

## Examples

``` r
if (FALSE) { # \dontrun{
get_aoi_region_sets()
} # }
```

# sets the starting point of a given trial to be zero

sets the starting point of a given trial to be zero

## Usage

``` r
ds.rezero_times(df_table)
```

## Arguments

- df_table:

  to-be-resampled dataframe with t, aoi/xy values, trial_id and
  administration_id

## Value

df_out with resampled time, xy or aoi value rows

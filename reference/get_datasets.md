# Get datasets

**\[superseded\]**

Use `pb$datasets` on a
[`peekbank()`](https://peekbank.github.io/peekbankr/reference/peekbank.md)
client.

## Usage

``` r
get_datasets(connection = NULL)
```

## Arguments

- connection:

  A connection to the peekbank database

## Value

A tibble of Datasets data.

## Examples

``` r
if (FALSE) { # \dontrun{
get_datasets()
} # }
```
